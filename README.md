## Shipping right now

### 📦 [kpr](https://kpr.nrtn.io/) — keeper for your homelab registry

Push `app:10m` to your registry and the tag is gone ten minutes later.

kpr fronts a stock OCI `distribution` registry: ephemeral images and lightweight retention cleanup, without running Harbor or Nexus. One Go binary, plain-file state (no database to run), policies as Go code instead of a rule language. Code: [github.com/noroutine/kpr](https://github.com/noroutine/kpr).
